What is শারদ ভ্রমণ?

শারদ ভ্রমণ is a dedicated Kolkata Durga Puja Pandal Hopping & Navigation Guide designed to make exploring the city's Puja pandals easier, more organized, and less stressful.

The app brings together Pandal information, Google Maps navigation, Metro and Railway Station-based planning, North & South Kolkata routes, nearby toilets and restaurants, Bonedi Bari Puja, Theme Puja, and Kalyani Puja in one convenient place.

The name “শারদ ভ্রমণ” reflects the core idea: exploring Kolkata during the festive Sharad season with a simple, organized, and location-focused guide.

Why শারদ ভ্রমণ?
Pandal hopping made easier — Discover and plan visits to Durga Puja pandals without having to search for every location individually.
Google Maps guidance — Each pandal section includes map guidance to help you navigate to your selected destination.
Station-based planning — Find pandals conveniently based on nearby Metro and Railway Stations.
North & South Kolkata organization — Explore Kolkata Puja pandals through dedicated North Kolkata and South Kolkata sections.
Essential facilities nearby — Quickly find nearby toilets and restaurants around each pandal section.
Beyond regular pandals — Explore dedicated Bonedi Bari Puja and Theme Puja sections.
Explore beyond Kolkata — A dedicated Kalyani section helps you discover Puja destinations outside the main Kolkata sections.
No phone permissions required — শারদ ভ্রমণ is designed to work without requiring unnecessary phone permissions.

# Deployment

The website is **auto-deployed**: every push to `main` triggers a build + deploy to Cloudflare Pages via the connected Git integration (project `naihatinights`).

- **Production URL:** https://naihatinights.pages.dev
- **Cloudflare account:** videshkarmakar@gmail.com

Manual deploy (optional), run from the project root:

```cmd
deploy.cmd
```

What it does: `bun install` → `bun run build` → `wrangler pages deploy dist --project-name=naihatinights`.

## How to update the website

1. Change code (components, `src/data/config.ts`, screenshots, etc.)
2. Commit and push:

   ```cmd
   git add -A
   git commit -m "describe your change"
   git push origin main
   ```

3. The live site updates automatically within a few minutes.
